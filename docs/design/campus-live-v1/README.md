# Campus Live：东大主场 V1

状态：待设计确认。该目录是独立静态设计预览，不是正式客户端，不连接 API，不改变直播与点播服务。

## 查看方案

在项目根目录执行：

```bash
python3 -m http.server 8091 --bind 127.0.0.1 --directory docs/design/campus-live-v1
```

浏览器打开 `http://localhost:8091`。也可以直接打开本目录的 `index.html`。无需 npm 安装或 Docker 重建。

- 底部工具栏切换首页、直播列表、直播间、点播库、点播详情及设计系统。
- 状态选择器切换正常、暂无内容、加载异常；可操作项目筛选、搜索、排序和页面跳转。
- 播放区为视觉占位，点击后明确提示设计预览。没有接入真实视频。
- 比赛、时间、时长为虚构示例；篮球图片是 AI 示意，不是东大实拍。详见 `assets/README.md`。

完整页面结构、设计理由、Design Tokens、东大元素来源、数据边界和 Vue 迁移步骤见 [DESIGN.md](DESIGN.md)。

## 本阶段验证（2026-09-13）

使用 Windows 上隔离的无头 Edge / Playwright 实际渲染：6 个视图 × 1440、1280、1024、390 像素，共 24 个布局。检查未发现横向溢出、破损图片或脚本异常；验证了分类筛选、无搜索结果、错误重试、空状态和播放器预览说明。人工查看首页、直播间、点播库及手机截图。

人工复验：逐个切换上述页面与宽度，确认标题与正文无遮挡、封面比例一致、筛选与状态按钮可用、键盘 focus 可见。

本阶段只增加设计材料，未改动应用代码；Vue 的 lint、typecheck、build、单元测试与真实播放验收在设计确认后实施，不能将静态预览验证等同于正式客户端验收。
