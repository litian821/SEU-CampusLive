# Campus Live：东大主场 V1 静态设计稿

该目录保存 Campus Live 第一版高保真静态设计稿，用于回顾产品结构、视觉方向和东南大学元素使用方式。正式运行客户端已经迁移到 `apps/web/` 的 Vue 3 实现；本目录不连接 API，也不承担生产运行。

## 查看方式

在项目根目录执行：

```bash
python3 -m http.server 8091 --bind 127.0.0.1 --directory docs/design/campus-live-v1
```

浏览器打开：

```text
http://127.0.0.1:8091
```

也可以直接打开本目录的 `index.html`。静态预览无需 npm 安装或 Docker 重建。

## 内容说明

- 底部工具栏用于切换首页、直播列表、直播间、点播库、点播详情和设计系统。
- 状态选择器用于切换正常、暂无内容和加载异常。
- 播放区是视觉占位，不是真实播放器。
- 早期设计中的部分比赛、时间和时长是为了展示布局而设置的示例，不代表真实赛事。
- 当前正式客户端已使用用户提供的篮球实拍图调色版本，并新增“赛场瞬间”页面。

完整页面结构、设计理由、设计变量、东南大学元素来源和落地边界见 [DESIGN.md](DESIGN.md)。

## 验证记录

2026-09-13 使用 Windows 上隔离的无头 Edge / Playwright 渲染过 6 个视图、4 个宽度，共 24 个布局。检查未发现横向溢出、破损图片或脚本异常；验证了分类筛选、无搜索结果、错误重试、空状态和播放器预览说明。

静态预览验证不能等同于正式客户端验收。正式客户端的 Vue lint、类型检查、单元测试、生产构建、浏览器播放和 RTMP/HLS 媒体链路验收见 `docs/testing.md` 与 `docs/validation-2026-09-13.md`。
